# AI Resume Generator

A modern ATS-friendly Resume Generator web application that helps users create professional resumes with live preview, multiple templates, AI-powered suggestions, and PDF export functionality.

---

# Features

- ATS-Friendly Resume Templates
- Live Resume Preview
- Export Resume as PDF
- Multiple Professional Templates
- Dark & Light Mode
- AI Professional Summary Generator
- Skill Suggestions Based on Job Role
- Resume Score Checker
- Grammar Correction
- Drag-and-Drop Resume Sections
- Dynamic Add/Remove Sections
- Portfolio Website Generator
- AI Cover Letter Generator
- QR Code for Contact/Portfolio
- Mobile Responsive UI
- Fast and Smooth User Experience
